# 📖 Overview

The **Student Grade Dashboard** is a responsive React application for managing student records through a clean and intuitive interface.

It allows users to add, edit, delete, search, filter, and organize student information while automatically calculating grades and persisting data using Local Storage.

---

# ✨ Features

### 🎓 Student Management

- Add new student records
- Edit existing student details
- Delete students with confirmation
- Automatic grade calculation

### 🔍 Search & Organization

- Search by student name
- Search by subject
- Filter by grade
- Sort by name
- Sort by marks

### 📊 Dashboard

- Total students
- Average marks
- Highest grade
- Subject overview

### 🎨 User Experience

- Responsive design
- Toast notifications
- Confirmation modal
- Local Storage persistence
- Clean and modern interface

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/saikiran-ravuri/student-grade-dashboard.git
```

### Navigate to the project

```bash
cd student-grade-dashboard
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

### Build for production

```bash
npm run build
```
